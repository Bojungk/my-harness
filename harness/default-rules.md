# 기본값 — 디자인 규칙

> 작성 2026-10-11 · 근거: `design.md` · 값은 `default-tokens.md`
> 출처 표시는 `default-tokens.md`와 같다. ⚠️ `[임의]`는 design.md에 없는 것.

## R1. 접근성 `[D]`

| # | 규칙 | 기준 |
|---|---|---|
| R1-1 | 텍스트와 배경 대비 4.5:1 이상 | WCAG 2.1 SC 1.4.3 |
| R1-2 | 기능적 경계선·UI 요소 대비 3:1 이상. 선이 얇아도 예외 없음 | WCAG 2.1 SC 1.4.11 |
| R1-3 | `tertiary/500` 채움 위에는 흰 글자를 쓰지 않는다 (2.99:1) | |
| R1-4 | 대비는 텍스트 → 채움 → 표면 3겹 합성 기준으로 잰다 | |
| R1-5 | 대비 등급은 흰 글자 / 어두운 글자 기준을 나눠 적는다 | |

## R2. 토큰 구조 `[D]`

| # | 규칙 |
|---|---|
| R2-1 | 토큰 이름에 모드(`light`, `dark`)를 넣지 않는다. 모드는 Figma Variables 모드로 나눈다 |
| R2-2 | 번호 체계는 50~950 하나만 쓴다 |
| R2-3 | 어느 팔레트에도 없는 색(고아 값)을 쓰지 않는다 |
| R2-4 | 토큰 1개에 값 1개 |
| R2-5 | 반투명은 배경 레이어에만. 텍스트·기능 경계는 불투명 |

## R3. 타이포그래피 `[D]`

| # | 규칙 |
|---|---|
| R3-1 | Pretendard, weight는 400 / 500 / 700만 |
| R3-2 | 위계는 크기와 색으로 만든다. 같은 크기의 패밀리를 용도로만 나누지 않는다 |
| R3-3 | 큰 글자에 150% 행간을 그대로 쓰지 않는다 |
| R3-4 | Display 자간은 음수 (−1.5%) |

## R4. 작업 순서 `[D]`

| # | 규칙 |
|---|---|
| R4-1 | 컴포넌트보다 Figma Variables 연결이 먼저다 |
| R4-2 | 기본 프리미티브(Button, Text Input, Textarea, Select, Checkbox, Radio, Switch, Badge, Tag, Chip, Dialog)는 기획 확정 전 착수 가능 |
| R4-3 | 도메인 컴포넌트는 기획 확정 후 |
| R4-4 | 이 서비스의 도메인 컴포넌트: 자료 카드, 카테고리 보드, 분류 제안·승인 UI ⚠️ `[임의]` PRD 화면에서 추린 것 |

## 없는 것

`design.md`에 템플릿과 잘 나온 예시는 들어 있지 않았다. 체크리스트도 별도로 없어서, 위 규칙을 `story-work.md` 게이트로 옮겨 체크리스트로 썼다.
