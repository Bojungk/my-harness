> 사용자가 값을 정하지 않은 항목은 이 파일의 값으로 진행한다. 사용자가 정하면 그 값이 우선한다.

## 출처 표시

| 표시 | 뜻 |
|---|---|
| `[D]` | `design.md`에 값이 그대로 적혀 있음 |
| `[D·계산]` | `design.md`의 문장·대비 수치로 역산했고, WCAG 공식으로 재계산해 일치를 확인함 |
| `[Tailwind]` | `design.md`가 "Gray = Tailwind 채택"이라고만 적어서, 값은 Tailwind 표준에서 가져옴 |
| ⚠️ `[임의]` | **design.md에 없음. Claude가 진행용으로 넣은 값. 확인 필요** |

## 6. 아직 기본값도 없는 것

`design.md`에서도 "정의 필요"로 남아 있어 임의 값을 넣지 않았다.

- 포커스 링 (design.md가 "가장 시급"으로 표시)
- Shadow · 그래픽 컬러 · Primary 테두리(#d8e5fd는 원본 확인 필요로 표시돼 있음)
- 다크모드 값 · 브레이크포인트
