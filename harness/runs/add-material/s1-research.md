## 분석

자료 추가 화면에는 두 가지 입력 경로가 있다. 링크를 붙여넣고 카테고리를 직접 고르는 경로(스토리 1)와, 노션·북마크에서 자동으로 불러온 자료의 분류 제안을 확인하고 승인하는 경로(스토리 2)다. 레퍼런스도 이 두 갈래로 나눠서 봤다. 모두 PC 웹 화면이고, 유아이볼 무료 검색 결과(쿼리당 최대 3개) 안에서 골랐다.

**직접 추가 경로 (스토리 1)**
- 모각작의 그룹 생성은 현재 페이지 위에 모달을 띄우고, 텍스트 필드에 입력해 확정하면 토스트로 결과를 알린다. 페이지를 옮기지 않으니 보드 맥락이 유지된다. 링크 입력, 카테고리 선택, 저장을 모달 하나에서 끝내면 클릭 수를 줄일 수 있다(3클릭 규칙).
- 요즘IT 북마크는 저장한 항목을 폴더(분류) 단위 카드로 보여 주고, 왼쪽 목록에서 폴더를 바로 고를 수 있다. 저장 결과가 "보드에 카드로 쌓인다"(스토리 1의 마지막 단계)를 보여 주는 형태로 참고할 만하다. 카테고리 선택지를 기존 폴더 목록으로 보여 주는 방식도 여기서 가져온다.

**자동 불러오기 경로 (스토리 2)**
- 슬랙 관리자의 데이터 가져오기는 외부 소스(Slack, CSV 등)를 한 줄씩 나열하고 줄마다 "가져오기" 버튼을 둔다. 소스 선택이 한 화면에서 끝난다. 노션·북마크 연결 진입점을 같은 목록형으로 두면 된다.
- 사방넷의 상품 자동 매칭 안내는 AI 자동 매칭이 무엇을 하는지 모달에서 먼저 설명하고, 체크박스로 사용자가 직접 선택하게 한다. AI가 바로 실행하지 않고 사용자가 먼저 확인하는 구조라서 서비스 원칙 2("AI가 사용자 확인 없이 자동 분류하지 않는다")와 맞는다.
- 매니패스트는 AI 제안 내용을 사이드 패널에 칩·태그로 보여 주고, 사용자가 검토한 뒤 반영하는 흐름이다. 불러온 자료마다 "제안 카테고리"를 칩으로 보여 주고, 승인하거나 다른 카테고리로 바꾸는 UI에 적용할 수 있다.

**종합**
- 직접 추가는 모달 한 장으로 붙여넣기, 카테고리, 저장을 마치고 토스트로 끝낸다.
- 자동 불러오기는 소스 목록, 분류 제안 검토, 사용자 승인, 보드 반영 순서를 지키고, 승인 전에는 아무것도 보드로 옮기지 않는다.
- 썸네일 수준에서 관찰한 내용이라 세부 수치(간격, 색상)는 근거로 쓰지 않는다.
