## 화면 정보
- screen: add-material
- 담당 스토리: 1, 2

## 주요 요소
| 요소 | 설명 |
|---|---|
| 자료 추가 모달 | 홈 대시보드 보드 위에 뜨는 모달. 페이지를 옮기지 않아 보드 맥락이 유지된다. 탭 없이 위쪽에 "직접 추가" 영역, 아래쪽에 "불러오기" 영역을 함께 보여 줘서 영역 전환에 클릭을 쓰지 않는다 |
| 링크 입력 필드 | 강의 링크를 붙여넣는 텍스트 필드. 모달이 열리면 바로 포커스가 들어간다 (스토리 1) |
| 카테고리 선택 목록 | 기존 분류(출처 → 학습 주제) 목록에서 하나를 고르는 드롭다운. 최근 쓴 카테고리가 맨 위에 온다 (스토리 1) |
| 저장 버튼 | 링크와 카테고리가 채워지면 활성화된다. 누르면 모달이 닫히고 해당 카테고리에 카드로 쌓인다 (스토리 1) |
| 완료 토스트 | "보드에 추가됨" 알림과 "보기" 링크. "보기"를 누르면 해당 카테고리 상세로 간다 (스토리 1) |
| 불러올 소스 목록 | "불러오기" 영역에서 노션·북마크 소스를 한 줄씩 나열하고 줄마다 "불러오기" 버튼을 둔다 (스토리 2) |
| AI 안내 문구 | 소스 목록 위의 한 줄 안내: "AI는 카테고리를 제안만 합니다. 승인한 자료만 보드에 들어갑니다." 별도 모달 없이 클릭 수를 늘리지 않는다 (스토리 2) |
| 제안 검토 목록 | 불러온 자료를 행마다 체크박스, 제목, AI 제안 카테고리 칩으로 보여 준다. 칩을 누르면 다른 카테고리로 바꿀 수 있다. 체크박스는 기본 선택 상태지만 승인 전에는 아무것도 보드로 옮기지 않는다 (스토리 2) |
| 선택 항목 승인 버튼 | 체크된 자료만 보드에 반영한다. 옆에 "취소" 버튼을 두고, 취소하면 아무것도 반영하지 않는다 (스토리 2) |

## 클릭 경로
| 목표 자료 | 경로 | 클릭 수 |
|---|---|---|
| 강의 링크를 카테고리에 추가 (스토리 1) | 홈 "자료 추가" 클릭 → (링크 붙여넣기는 키 입력) 카테고리 선택 → 저장 클릭 | 3 |
| 방금 추가한 자료 확인 (스토리 1) | 홈에서 해당 카테고리 카드 클릭 → category-detail에서 자료 카드 클릭 | 2 |
| 노션 자료 불러와 보드에 반영 (스토리 2) | 홈 "자료 추가" 클릭 → "불러오기" 영역의 노션 줄 "불러오기" 클릭 → 제안 확인 후 "선택 항목 승인" 클릭 | 3 |
| 북마크 자료 불러와 보드에 반영 (스토리 2) | 홈 "자료 추가" 클릭 → 북마크 줄 "불러오기" 클릭 → "선택 항목 승인" 클릭 | 3 |

## 자동 불러오기 흐름
| 순서 | 단계 |
|---|---|
| 1 | 소스 선택: 노션 또는 북마크 줄의 "불러오기" 버튼을 누른다 |
| 2 | 자료 가져오기: 선택한 소스의 자료 목록을 읽어 온다. 보드에는 아직 아무것도 들어가지 않는다 |
| 3 | 분류 제안: AI가 자료마다 제안 카테고리를 칩으로 보여 준다. 사용자는 체크박스로 반영할 자료를 고르고 칩을 눌러 카테고리를 바꿀 수 있다 |
| 4 | 사용자 승인: "선택 항목 승인"을 눌러야만 다음 단계로 간다. "취소"하면 아무것도 반영하지 않는다 |
| 5 | 보드 반영: 승인한 자료만 해당 카테고리에 카드로 쌓이고 "보드에 추가됨" 토스트를 띄운다 |
