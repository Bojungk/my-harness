## 리서치 정리

세 프레임은 home-dashboard 행 아래(y=3372)에 놓았다. 헤더·사이드바·탭·정렬·유형 배지·"+ 자료 추가" 버튼·빈 화면 틀은 category-detail 01·03(10:2, 10:215)의 변수 바인딩된 노드를 복제해서 썼다. 색·radius·간격·글자 크기는 모두 로컬 컬렉션 "Sossbar tokens"에 바인딩했고, 새 변수는 만들지 않았다. 서체는 Noto Sans KR 400/500/700만 쓴다. 사이드바의 출처→학습 주제 데이터(인프런: React 기초·Next.js 실전 / 유튜브: 디자인 시스템 / 노션: 데이터 분석 / 북마크: 커리어)는 기존 화면과 같다.

**1 · 검색 결과 기본 ('React' 7건)**
- 마플: 헤더 검색창에 입력한 키워드를 그대로 남기고(지우기 X 포함), 결과 영역 맨 위에 "'React' 검색 결과 7건"을 한 줄로 보여 준다. 무엇을 검색했고 몇 건이 나왔는지 바로 알 수 있다.
- 리디: 결과 위에 전체 7·링크 2·교안 2·강의 3 탭을 둔다. 필터 패널을 열지 않고 탭 한 번으로 유형을 좁힌다(스토리 4). 탭 스타일은 category-detail 것을 그대로 쓴다.
- 교보문고: 좌측 사이드바 자리에 출처→학습 주제 체크박스 필터를 두고, 결과 카드 오른쪽에 "열기" 버튼을 둔다. 검색창 클릭 → "열기"의 2클릭으로 끝난다(스토리 5, 원칙 1).
- 인프런: 카드마다 유형 배지(링크·교안·강의)와 카테고리 태그(예: 인프런 > React 기초), 추가한 날짜를 넣었다. 서로 다른 유형을 한 목록에 섞어도 어느 분류의 자료인지 카드만 보고 알 수 있다. 카테고리 태그를 누르면 category-detail로 간다(스토리 3). 제목의 키워드는 primary/500 Bold로, 태그 안의 키워드는 Bold로만 강조했다. 회색 태그 위의 primary 글자는 대비가 4.27이라 쓰지 않았다.
- 읽기 전용: 카드에는 "열기"와 태그 이동만 있다. 분류·이동·삭제 동작은 넣지 않았다. 필터 아래에 "필터는 보이는 결과만 좁혀요. 자료의 카테고리는 바뀌지 않아요."라고 적었다(스토리 규칙 2).

**2 · 학습 주제 필터 적용 (5건)**
- 교보문고: 좌측에서 React 기초를 체크하면 결과 위에 "적용된 필터" 칩(인프런 > React 기초 ×)과 "필터 모두 해제"가 나타난다. 칩의 X로 바로 푼다. 상위 출처(인프런)는 일부 선택 상태로 보인다. 결과 수와 탭 숫자도 5건 기준으로 바뀐다. 검색창 클릭 → 학습 주제 체크 → "열기"의 3클릭이다.

**3 · 결과 없음 ('useEfect' 0건)**
- 훗타운·리디: category-detail의 빈 화면 틀을 재사용하되 아이콘을 돋보기로 바꾸고 "찾는 자료가 없어요" + 철자 확인 안내를 넣었다. 그 아래에 제안 키워드 칩(useEffect·React 훅·상태 관리), "카테고리 보드로 돌아가기"(보조 버튼)와 "+ 자료 추가"(주 버튼), 최근 검색어 칩(React·포트폴리오·이력서)을 두어 막다른 길을 만들지 않았다. 제안 칩 클릭 → "열기"로 3클릭 안에 끝난다.

**대비 확인**
- 텍스트: 본문 gray/900, 보조 gray/600·gray/700, 메타 gray/500(흰 배경 4.83, gray/50 배경 약 4.6)으로 모두 4.5:1 이상이다. primary/500 버튼 위 흰 글자는 4.68이다. tertiary/500은 쓰지 않았다.
- 기능 경계: 검색창·"열기"·보조 버튼·체크박스·정렬·제안/최근 칩은 border/functional(gray/500, 4.83)을 쓴다. 적용 필터 칩은 primary/500 테두리(primary/50 위 약 4.2)다. 체크된 체크박스는 primary/500 채움(4.68)이다.
- 카드 테두리는 기존 화면과 맞춰 border/decorative(gray/200)를 그대로 썼다. 장식 경계라 3:1 기준 밖으로 두었다. 이것은 보고만 한다.

## 디자인 시스템 보정 (2026-10-11)
- 15-2와 16-196은 미바인딩이 0건이라 바꾼 것이 없다.
- 16-2는 1건을 바꿨다. 사이드바에서 선택된 "React 기초" 행의 개수 "5"가 primary/50 위의 gray/500이라 대비가 4.25:1이었다. 이 글자를 gray/600으로 올렸다(약 6.6:1). category-detail 사이드바처럼 선택 행 숫자를 진하게 하는 규칙과 같다.
