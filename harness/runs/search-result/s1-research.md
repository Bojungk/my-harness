## 분석

검색 결과 화면은 스토리 5("포트폴리오 작업 중 필요한 예전 교안을 키워드로 검색해 연다")를 맡는다. 키워드 입력부터 자료 열기까지 3번 클릭 안에 끝나야 하고(서비스 원칙 1), 결과는 사용자가 이미 아는 분류(출처 → 학습 주제, 스토리 3)로 좁힐 수 있어야 한다. 레퍼런스는 모두 PC 웹 화면이고, 유아이볼 무료 검색 결과(쿼리당 최대 3개) 안에서 골랐다. 일일 무료 조회 한도에 걸려 추가 검색은 하지 못했다.

**결과 목록 구성 (스토리 5, 4)**
- 교보문고는 결과 한 줄에 썸네일, 제목, 메타 정보(저자·출판사 등)를 두고 행 오른쪽에 바로 실행 버튼을 둔다. 상세 페이지를 거치지 않고 목록에서 바로 행동할 수 있다. 우리 서비스에서는 결과 카드에 "열기"를 두면 검색, 결과 클릭(또는 열기) 2단계로 끝나 3클릭 규칙을 지키기 쉽다.
- 마플은 헤더 검색창에 입력한 키워드를 그대로 남겨 두고, 결과 영역 위에 키워드와 결과 수를 한 줄로 보여 준 뒤 카드 그리드를 깐다. 무엇을 검색했고 몇 건이 나왔는지 바로 알 수 있다.
- 인프런은 좌측 카테고리 목록과 우측 카드 목록을 한 화면에 둔다. 카드에는 태그가 붙어 있어 어느 분류의 자료인지 카드만 보고도 알 수 있다. 링크·교안·강의라는 자료 유형을 카드 배지로 구분해 "모은 자료를 한 화면에서 본다"(스토리 4)는 감각을 검색 결과에서도 유지할 수 있다.

**좁히기 (스토리 3)**
- 교보문고는 좌측에 체크박스 필터 그룹을, 상단에 탭(통합/분야별)과 정렬 드롭다운을 둔다. 필터를 고르면 칩으로 상단에 표시된다. 우리 서비스의 출처 → 학습 주제 계층을 좌측 필터 그룹으로 그대로 옮기면, 홈 보드에서 쓰던 분류로 결과를 좁힐 수 있다.
- 리디는 결과 상단 탭으로 자료 유형을 나눈다. 링크·교안·강의 탭(또는 칩)으로 쓰면 필터 패널을 열지 않고 한 번에 좁힐 수 있다.

**검색 전·결과 없음 상태 (스토리 5)**
- 훗타운은 검색 패널을 열면 입력창 아래에 최근 검색어 칩과 인기 검색어 목록을 보여 주고, 결과가 없을 때는 빈 화면으로 안내한다. 리디도 검색창 아래 최근 검색어 영역을 두고, 없을 때는 안내 문구를 띄운다. 같은 교안을 반복해서 찾는 사용자에게 최근 검색어 칩은 재입력 없이 한 번에 결과로 가는 지름길이 된다.
- 결과 없음 화면에는 다른 키워드 제안이나 카테고리 보드로 돌아가는 경로를 두어 막다른 길을 만들지 않는다.

**종합**
- 상단: 키워드가 남아 있는 검색창, 키워드와 결과 수 한 줄, 자료 유형 탭.
- 좌측: 출처 → 학습 주제 필터. 선택한 필터는 칩으로 상단에 보여 준다.
- 본문: 유형 배지·카테고리 태그가 붙은 결과 카드, 카드마다 바로 "열기".
- 검색 전에는 최근 검색어 칩을, 결과가 없으면 빈 화면과 보드로 돌아가는 경로를 보여 준다.
- 썸네일 수준에서 관찰한 내용이라 세부 수치(간격, 색상)는 근거로 쓰지 않는다.
