## 화면 정보
- screen: search-result
- 담당 스토리: 5, 4, 3

## 주요 요소
| 요소 | 설명 |
|---|---|
| 헤더 검색창 | 홈 대시보드와 같은 위치의 검색창. 입력한 키워드가 그대로 남아 있어 바로 고쳐서 다시 검색할 수 있다. Enter로 검색한다 (스토리 5) |
| 최근 검색어 칩 | 검색창을 누르면 입력창 아래에 최근 검색어 칩을 보여 준다. 칩을 누르면 다시 입력하지 않고 바로 결과로 간다 (스토리 5) |
| 결과 요약 줄 | 결과 영역 맨 위에 "'키워드' 검색 결과 N건"을 한 줄로 보여 준다 (스토리 5) |
| 자료 유형 탭 | 결과 위의 전체·링크·교안·강의 탭. 탭 한 번으로 유형을 좁히고, 필터 패널을 열 필요가 없다 (스토리 4) |
| 좌측 분류 필터 | 홈 보드와 같은 출처 → 학습 주제 계층의 체크박스 목록. 고른 필터는 결과 위에 칩으로 표시되고, 칩의 X로 바로 해제한다. 필터는 결과 보기만 좁히고 자료의 카테고리를 바꾸지 않는다 (스토리 3) |
| 결과 카드 | 링크·교안·강의 자료를 한 목록에 섞어 보여 준다. 카드마다 유형 배지, 제목, 카테고리 태그(출처 · 학습 주제), 키워드 강조, 추가한 날짜를 둔다 (스토리 4, 5) |
| "열기" 버튼 | 결과 카드 오른쪽에 둔다. 누르면 상세를 거치지 않고 원본 자료(링크·교안 파일·강의 영상)를 새 탭에서 연다 (스토리 5) |
| 카테고리 태그 | 결과 카드의 태그를 누르면 그 자료가 속한 카테고리 상세로 간다 (스토리 3) |
| 결과 없음 화면 | 결과가 0건이면 "찾는 자료가 없어요" 안내와 함께 비슷한 키워드 제안 칩, "카테고리 보드로 돌아가기" 버튼, "자료 추가" 버튼을 보여 준다. 막다른 길을 만들지 않는다 (스토리 5) |
| 읽기 전용 원칙 | 검색 결과 화면에서는 자료를 분류·이동·삭제하지 않는다. AI가 결과를 보고 카테고리를 바꾸거나 정리하는 동작이 없다. 정렬과 필터는 보이는 순서와 범위만 바꾼다 |
