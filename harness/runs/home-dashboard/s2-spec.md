## 화면 정보
- screen: home-dashboard
- 담당 스토리: 1, 2, 3, 4, 5

## 주요 요소
| 요소 | 설명 |
|---|---|
| 왼쪽 사이드 네비게이션 | 출처(1단) → 학습 주제(2단) 트리. 학습 주제를 누르면 바로 해당 카테고리 상세로 간다. 홈에서 어느 카테고리든 1클릭이다 (스토리 3) |
| 헤더 검색창 | 헤더 가운데에 늘 보이는 검색창. 키워드를 입력하고 Enter를 누르면 검색 결과로 간다 (스토리 5) |
| 자료 추가 버튼 | 헤더 오른쪽, 검색창 옆의 고정 버튼. 누르면 홈 보드 위에 자료 추가 모달(add-material)이 뜬다. 페이지를 옮기지 않아 보드 맥락이 유지된다 (스토리 1) |
| 분류 제안 승인 대기 카드 | 본문 맨 위 알림 카드. "자동 불러오기에서 분류 제안 N건이 승인 대기 중이에요"와 "검토하기" 버튼을 보여 준다. 대기 건이 0이면 카드를 숨긴다. 카드는 안내만 하며, 이 카드가 떠 있는 동안에도 보드·카운트·최근 자료 목록에는 대기 중인 자료를 반영하지 않는다. "검토하기"를 누르면 add-material 모달이 제안 검토 목록 상태로 열리고, 거기서 "선택 항목 승인"을 눌러야만 보드에 반영된다 (스토리 2) |
| 학습 주제 카드 보드 | 학습 주제별 카드를 그리드로 깐다. 카드마다 주제 제목, 출처 이름, 자료 수를 보여 준다. 카드를 누르면 해당 카테고리 상세로 간다 (스토리 3) |
| 출처별 요약 카드 | 출처마다 카드 하나. 카드 안에 링크·교안·강의 건수 3가지만 보여 준다. 카드를 누르면 해당 출처의 첫 학습 주제 카테고리 상세로 간다 (스토리 4) |
| 최근 추가 자료 목록 | 홈 하단. "전체 / 링크 / 교안 / 강의" 유형 탭으로 나눈 최근 자료 목록. 항목마다 제목, 유형, 카테고리, 추가 날짜를 보여 주고, 항목을 누르면 자료가 바로 열린다. 승인된 자료만 나온다 (스토리 4) |
| 완료 토스트 | add-material에서 저장 또는 승인 후 홈으로 돌아오면 "보드에 추가됨"과 "보기" 링크를 띄운다. "보기"를 누르면 해당 카테고리 상세로 간다 (스토리 1, 2) |

| 최근 추가한 교안 열기 (스토리 4) | 최근 추가 자료 목록의 "교안" 탭 클릭 → 자료 항목 클릭 | 2 |
