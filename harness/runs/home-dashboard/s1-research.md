## 분석

홈 대시보드는 시나리오 B의 출발점이다. 접속하면 출처 → 학습 주제 순으로 나뉜 보드가 보이고(스토리 3), 그동안 모은 자료가 한 화면에 요약돼야 한다(스토리 4). 동시에 자료 추가(스토리 1·2)와 검색(스토리 5)으로 가는 출발점이기도 하다. 그래서 레퍼런스를 "관리형 대시보드"(당근 비즈니스, 사방넷)와 "분류형 콘텐츠 홈"(네이버 웹툰, 쿠팡, 알라딘) 두 갈래로 봤다. 모두 PC 웹 화면이고, 유아이볼 무료 검색 결과(쿼리당 최대 3개, 일일 한도 내) 안에서 골랐다.

**관리형 대시보드**
- 당근 비즈니스 관리자 홈은 왼쪽에 고정 사이드 네비게이션을 두고, 본문 맨 위에 "지금 처리할 일" 알림 카드와 실행 버튼을, 그 아래 최근 기간 요약 지표를 타일 4개로 나란히 둔다. 사이드 네비게이션을 출처(1단) → 학습 주제(2단) 트리로 쓰면 어느 카테고리든 홈에서 1클릭으로 들어간다(스토리 3, 3클릭 규칙). 상단 알림 카드는 "자동 불러오기에서 분류 제안 N건이 승인 대기 중" 같은 안내에 맞다. 승인은 사용자가 버튼을 눌러야만 진행되므로 서비스 원칙 2와 충돌하지 않는다(스토리 2).
- 사방넷 대시보드는 영역(주문·상품·CS 등)마다 카드를 하나씩 두고 카드 안에 항목별 건수를 크게 보여 준다. 카드 하나가 곧 하나의 분류 요약이다. 출처별 카드 안에 링크·교안·강의 건수를 보여 주면 "그동안 모은 것"을 한 화면에서 파악할 수 있다(스토리 4). 다만 정보 밀도가 매우 높아서 그대로 가져오면 취업 준비생에게 과하다. 카드 수와 숫자 종류는 줄인다.

**분류형 콘텐츠 홈**
- 네이버 웹툰 홈은 상단 탭으로 분류를 바꾸고 아래에 썸네일 카드 그리드를 깐다. 보드 영역에서 학습 주제 카드를 썸네일·제목·자료 수로 보여 주고, 카드 클릭 한 번으로 카테고리 상세로 넘어가는 구조에 쓸 수 있다(스토리 3).
- 쿠팡 홈은 좌상단 카테고리 메뉴 버튼과 가운데 큰 검색창을 헤더에 고정한다. 어느 화면에서든 검색이 첫 번째로 보인다. 헤더 검색창을 홈에 상시 노출하면 "예전 교안을 키워드로 검색해 연다"가 홈에서 바로 시작된다(스토리 5).
- 알라딘 보관함은 저장한 항목을 유형 탭으로 나눠 목록으로 보여 준다. 링크·교안·강의를 유형 필터(탭)로 나눠 최근 추가 자료 목록을 보여 주는 영역에 적용한다(스토리 4).

**종합**
- 레이아웃: 왼쪽 사이드 네비게이션(출처 → 주제 트리) + 상단 헤더(검색창, 자료 추가 버튼) + 본문(승인 대기 알림 → 주제 카드 보드 → 최근 자료 목록).
- 홈에서 카테고리 1클릭, 자료 열기는 카테고리 상세를 거쳐 2클릭이면 3클릭 규칙 안에 들어온다.
- 승인 대기 알림은 안내만 하고, 홈에서 AI가 자료를 옮기거나 분류하지 않는다.
- 썸네일 수준에서 관찰한 내용이라 세부 수치(간격, 색상)는 근거로 쓰지 않는다. 자료 추가 화면 리서치(모각작 모달)와 이어지도록 "자료 추가" 버튼은 홈 위에 모달을 띄우는 진입점으로 둔다.
