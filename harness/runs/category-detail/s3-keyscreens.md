## 리서치 정리

**화면 구성.** 왼쪽 280px 사이드바와 오른쪽 메인 영역으로 나눴다. S1 종합("왼쪽은 출처 → 학습 주제 2단계, 오른쪽은 제목·개수·탭·정렬·카드 리스트")을 그대로 따른 구성이다. 헤더(자료함 · 상단 검색창 · "+ 자료 추가")는 승인된 add-material 프레임(5:156)의 Header를 복제해 썼다. 그래서 홈·자료 추가·카테고리 상세가 같은 상단 바를 쓰고, 상단 검색창도 항상 같은 자리에 있다(유아이볼 폴더 상세, 스토리 5).

**사이드바: 요즘IT와 잔디 (스토리 3).** 요즘IT 북마크에서 "왼쪽 폴더 목록 + 오른쪽 내용" 배치를 가져왔다. 보드로 돌아가지 않고 옆 목록에서 다른 카테고리로 바로 옮기게 해 클릭 수를 줄이려는 것이다. 잔디의 접고 펴는 폴더 트리는 출처(상위, ▸/▾ 화살표)와 학습 주제(하위, 들여쓰기) 2단계로 바꿨다. 지금 보는 카테고리의 출처(인프런)는 펼친 상태로 열린다. 현재 학습 주제는 primary/50 배경, primary/500 세로 막대, 굵은 gray/900 글자로 강조했다. primary/50 위에서는 gray/500 글자가 4.5:1에 못 미친다. 그래서 선택된 행의 개수는 gray/700으로 올렸다. 맨 위에는 홈으로 가는 "보드" 링크를 뒀다. 3번 프레임은 사이드바에서 "Next.js 실전"으로 옮긴 결과다. 같은 화면 안에서 선택만 바뀌는 사이드바 이동을 보여 준다.

**카테고리 헤더와 탭·정렬: 유아이볼 (스토리 4).** 유아이볼 폴더 상세처럼 맨 위에 "인프런 > React 기초" 경로를 두고, 그 아래에 제목(20 Bold)과 "자료 5개"를 붙였다. 오른쪽에는 add-material과 같은 Primary 버튼("+ 자료 추가", 복제본)을 뒀다. 탭은 유아이볼의 스크린샷/플로우 탭을 "전체·링크·교안·강의"로 바꾼 것이다. 탭마다 개수를 붙였고, 기본값은 "전체"다. 선택한 탭은 Bold 글자와 primary/500 2px 밑줄로 표시했다. 정렬 메뉴는 유아이볼처럼 탭 줄 오른쪽 끝에 뒀다. 2번 프레임에서는 "강의" 탭을 고르고 정렬 메뉴(최근 저장순·제목순·출처순)를 연 상태다. 선택 항목 "제목순"에는 체크를 붙였고, 목록은 강의 3건을 제목순으로 다시 정렬해 보여 준다. 정렬 드롭다운과 메뉴는 조작하는 요소라서 테두리를 gray/500(4.83:1)으로 그었다.

**자료 카드: 네이버페이 (스토리 4, 5).** 네이버페이 관심 목록처럼 카드를 세로로 쌓았다. 카드마다 같은 순서로 유형 태그, 제목(16 Medium), "출처 · 저장일"(14, gray/500)을 넣었다. 유형 태그는 색에만 기대지 않도록 글자를 넣었다. 링크는 primary/50 채움, 교안은 gray/100 채움, 강의는 흰 바탕에 gray/500 테두리로 구분했다. 오른쪽 끝의 ↗ 아이콘은 카드를 한 번 누르면 원본이 새 탭으로 열린다는 뜻이다. 카드 데이터는 add-material 03 보드에 나온 React 기초 5건을 그대로 써서 보드에서 이어지는 흐름을 맞췄다. 카드 바깥 테두리(gray/200)는 승인된 자료 카드와 같은 장식선이다.

**빈 화면: 유아이볼 (스토리 4).** 유아이볼의 빈 폴더 화면처럼 카드 리스트 자리 가운데에 폴더 아이콘, "아직 자료가 없어요", 보조 문구, "+ 자료 추가" 버튼을 뒀다. 그래서 새로 만든 카테고리에서도 다음에 할 일이 바로 보인다. 정렬할 자료가 없으므로 정렬 메뉴는 숨기고, 탭은 개수 0으로 남겼다.

**디자인 시스템 반영.** 파일 안 라이브러리 검색에서 Sossbar 변수·스타일·컴포넌트는 나오지 않았다. 승인된 add-material 프레임도 변수 연결이 없는 hex 값이었다. 그래서 default-tokens.md 값만으로 로컬 변수 컬렉션 "Sossbar tokens"를 만들었다. 색(gray/50~950, primary/50·500, tertiary/500, 시맨틱 text/default·border/functional·border/decorative), radius/xs~xl, space/4~64, font-size/12·14·16·20이 들어 있다. 새 프레임 세 개의 채움·선·radius·패딩·간격·글자 크기는 모두 이 변수에 연결했고, 연결되지 않은 값은 0건이다. 서체는 Pretendard가 없어서 add-material과 같은 Noto Sans KR(400/500/700)을 썼다. Secondary·상태색은 쓰지 않았다. tertiary/500 위에는 흰 글자를 두지 않았다. 흰색은 default-tokens.md에 없지만 승인된 프레임의 헤더·카드·버튼 글자에 쓰여 있다. 이 값을 `base/white`로 변수화했으니 토큰 확정 때 확인이 필요하다.

## 디자인 시스템 보정 (2026-10-11)
- 10-2, 10-113, 10-215 세 프레임을 다시 감사했다. 미바인딩은 0건이라 바꾼 것이 없다.
- 카드·헤더·사이드바·툴바 테두리는 이미 border/decorative에, 검색창·정렬·정렬 메뉴·강의 태그 테두리는 border/functional에 연결돼 있다. 텍스트 대비 미달은 없다. 서체는 Noto Sans KR 400/500/700, 글자 크기는 20/16/14/12만 쓴다.
