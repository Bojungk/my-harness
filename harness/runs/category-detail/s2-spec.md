## 화면 정보
- screen: category-detail
- 담당 스토리: 3, 4, 5

## 주요 요소
| 요소 | 설명 |
|---|---|
| 상단 검색창 | 홈 대시보드와 같은 위치에 항상 두는 검색 필드. 키워드를 입력하고 Enter를 누르면 검색 결과 화면으로 간다 (스토리 5) |
| 카테고리 사이드바 | 왼쪽에 출처(상위) → 학습 주제(하위) 2단계 트리로 카테고리를 보여 준다. 지금 보고 있는 카테고리의 출처는 펼친 상태로 열리고 현재 학습 주제가 강조된다. 학습 주제를 누르면 보드로 돌아가지 않고 그 카테고리 상세로 바로 바뀐다 (스토리 3) |
| 출처 펼치기/접기 | 사이드바 출처 줄의 화살표. 누르면 하위 학습 주제를 펼치거나 접는다. 화면 이동은 없다 (스토리 3) |
| 카테고리 헤더 | 오른쪽 위에 "출처 > 학습 주제" 경로와 카테고리 제목, 자료 개수를 크게 보여 준다 (스토리 4) |
| 유형 탭 | 전체·링크·교안·강의 탭. 같은 화면 안에서 목록만 바꾸며, 기본은 "전체"라 첫 진입에 모든 자료가 보인다 (스토리 4) |
| 정렬 메뉴 | 탭 줄 오른쪽에 둔다. 최근 저장순(기본)·제목순·출처순 중 고른다 (스토리 4) |
| 자료 카드 리스트 | 자료 카드를 세로로 쌓는다. 카드마다 제목, 출처, 저장일, 유형 태그(링크/교안/강의)를 같은 구조로 넣는다. 카드를 한 번 누르면 원본 자료가 새 탭으로 열린다 (스토리 4, 5) |
| 자료 추가 버튼 | 카테고리 헤더 오른쪽에 둔다. 누르면 이 화면 위에 "자료 추가" 모달(add-material)이 뜨고, 카테고리 선택 목록에 현재 카테고리가 미리 선택되어 있다. 사용자가 저장을 눌러야만 카드가 쌓인다 (스토리 4) |
| 빈 화면 | 자료가 없는 카테고리에서 카드 리스트 대신 가운데에 "아직 자료가 없어요" 안내 문구와 "자료 추가" 버튼을 보여 준다 (스토리 4) |
| 보드로 돌아가기 | 사이드바 맨 위의 "보드" 링크. 누르면 홈 대시보드로 간다 (스토리 3) |

이 화면에서 AI는 자료를 분류·이동·삭제하지 않는다. 자료의 카테고리를 바꾸거나 지우는 동작은 이 화면 범위에 넣지 않는다.

## 다음 화면 경로
| 동작 | 이동 화면 |
|---|---|
| 상단 검색창에 키워드 입력 후 Enter | search-result |
| "자료 추가" 버튼 또는 빈 화면의 "자료 추가" 클릭 ("자료 추가" 모달이 이 화면 위에 뜸) | add-material |
| 사이드바에서 다른 학습 주제 클릭 | category-detail |
| 사이드바의 "보드" 링크 클릭 | home-dashboard |
| 자료 카드 클릭 (원본 자료를 새 탭으로 열고 이 화면은 그대로 둠) | category-detail |
