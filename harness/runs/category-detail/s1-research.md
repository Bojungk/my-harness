## 분석

카테고리 상세는 보드에서 카테고리를 클릭한 뒤 도착하는 화면이다(스토리 3). 여기서 그동안 모은 링크·교안·강의 목록을 한 화면에서 봐야 하고(스토리 4), 원하는 자료가 보이지 않으면 키워드로 좁혀 열 수 있어야 한다(스토리 5). 레퍼런스는 "저장한 것을 분류 단위로 다시 보는 화면"이라는 기준으로 골랐다. 모두 PC 웹 화면이고, 유아이볼 무료 검색 결과(쿼리당 최대 3개) 안에서 골랐다. 일일 무료 검색 한도에 걸려 목록·브레드크럼 조합 검색은 하지 못했다.

**카테고리 위치와 이동 (스토리 3)**
- 요즘IT 북마크는 왼쪽 내비게이션에 내 북마크 폴더 목록을 두고, 오른쪽에 선택한 폴더의 카드를 보여 준다. 다른 카테고리로 옮길 때 보드로 돌아가지 않고 옆 목록에서 바로 고를 수 있어서 클릭 수가 줄어든다(3클릭 규칙).
- 잔디는 왼쪽 사이드바에서 폴더를 접고 펴는 트리 구조로 보여 준다. 우리 분류 기준이 "출처 → 학습 주제" 2단계이므로, 사이드바에 출처를 상위로, 학습 주제를 하위로 두는 데 참고할 수 있다.

**한 화면에서 전체 자료 보기 (스토리 4)**
- 유아이볼 폴더 상세는 상단에 큰 폴더 제목과 저장 개수를 두고, 그 아래 탭으로 자료 유형(스크린샷/플로우)을 나눈다. 탭 아래 왼쪽에는 필터, 오른쪽에는 정렬과 주요 동작 버튼이 있다. 우리 화면에서는 탭을 "전체·링크·교안·강의"로 바꿔 한 화면 안에서 유형만 전환하게 하면 된다.
- 같은 화면은 자료가 없을 때 가운데에 안내 문구를 둔 빈 화면을 보여 준다. 새로 만든 카테고리에도 다음 행동(자료 추가)이 보이게 할 수 있다.
- 네이버페이 관심 부동산은 저장한 항목을 카드형 리스트로 세로로 쌓고, 카드마다 제목·요약 정보·태그를 보여 준다. 패널 상단에 정렬 옵션이 있다. 자료 카드에 제목, 출처, 저장일, 유형 태그를 같은 구조로 넣으면 목록을 훑기 쉽다.

**찾아서 열기 (스토리 5)**
- 유아이볼 폴더 상세는 상단 헤더에 검색창을 항상 둔다. 카테고리 상세에서도 상단 검색창을 유지해 키워드 검색으로 바로 넘어가게 한다. 카드 클릭 한 번으로 원본 자료가 열리게 하면 "보드 → 카테고리 → 자료" 3클릭 안에 들어온다.

**종합**
- 왼쪽: 출처 → 학습 주제 2단계 카테고리 목록. 오른쪽: 카테고리 제목·자료 개수, 유형 탭, 정렬, 카드 리스트.
- 카드 한 번 클릭으로 자료를 연다. 상단 검색창은 모든 화면에 유지한다.
- 썸네일 수준에서 관찰한 내용이라 세부 수치(간격, 색상)는 근거로 쓰지 않는다.
