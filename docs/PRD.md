---

## 1. 한 줄 정의

"[서비스명]는 **새로운 걸 계속 배우는 취업 준비생**이 **여기저기 흩어진 링크·강의교안·강의 영상**을 **직군·주제별로 한 화면에 모아 다시 꺼내 쓰는** 서비스다."

---

## 2. 주요 사용자 1명

- **누구**: 직무 전환을 준비하며 강의·아티클·자료를 계속 쌓는 취업 준비생
- **지금 지친 것**: 배운 자료가 바탕화면, 다운로드 폴더, 북마크, 카톡, 노션에 흩어져 있어서, 다시 쓰려는 순간 "그거 어디 있었지?"를 찾는 데 시간을 버린다.

---

## 3. 사용자 시나리오

### A. 자료 넣기 (가정)
1. 강의 링크를 받는다
2. 서비스에 붙여넣는다
3. 카테고리를 지정한다
4. 보드에 카드로 쌓인다

### B. 한눈에 보기
1. 서비스에 접속한다
2. 직군/주제별 보드를 확인한다
3. 원하는 카테고리를 클릭한다
4. 그동안 모은 링크·교안·강의 목록을 한 화면에서 본다

### C. 다시 꺼내 쓰기 (가정)
1. 포트폴리오 작업 중 예전 교안이 필요해진다
2. 키워드로 검색한다
3. 해당 자료를 연다

---

## 4. 만들 화면 (가정)

1. 홈 대시보드 (카테고리 보드)
2. 자료 추가
3. 카테고리 상세
4. 검색 결과

---

## 5. 지켜야 할 것 / 안 할 것

### 지켜야 할 것
- UI/UX를 고려해 만든다
  - 게이트 합격선 제안: **"원하는 자료까지 3번 클릭 안에 도달한다"** (측정 가능한 문장으로 구체화 필요)

### 안 할 것
- "멋대로 판단하지 않는다" — 적용 범위 확정 필요 (Q4)
  - 서비스 원칙이라면 제안 문장: **"AI가 사용자 확인 없이 자료를 자동 분류·이동·삭제하지 않는다"**
