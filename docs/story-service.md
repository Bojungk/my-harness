# 유저스토리 — 흩어진 학습 자료 정리 서비스 (가칭)

> 출처: `docs/PRD.md` · 사용자 확인 2026-10-11
> 이 문서는 "무엇을 위한 일인지"의 기준이다. 작업 방식(어떻게 하는지)은 여기에 섞지 않는다.

## 유저스토리

| # | 유저스토리 | PRD 근거 |
|---|---|---|
| 1 | 취업 준비생이 받은 강의 링크를 붙여넣고 카테고리를 지정해 보드에 카드로 쌓는다 | 시나리오 A |
| 2 | 취업 준비생이 노션·북마크에서 자동으로 불러온 자료의 분류 제안을 확인하고 승인해 보드에 쌓는다 | Q1 (사용자 확정) |
| 3 | 취업 준비생이 출처 → 학습 주제 순으로 나뉜 보드에서 원하는 카테고리를 클릭한다 | 시나리오 B, Q2 (사용자 확정) |
| 4 | 취업 준비생이 그동안 모은 링크·교안·강의 목록을 한 화면에서 본다 | 시나리오 B |
| 5 | 취업 준비생이 포트폴리오 작업 중 필요한 예전 교안을 키워드로 검색해 연다 | 시나리오 C |

## 이 서비스에서 어기면 안 되는 것

1. 원하는 자료까지 3번 클릭 안에 도달한다.
2. AI가 사용자 확인 없이 자료를 자동 분류·이동·삭제하지 않는다.
