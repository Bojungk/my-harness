## 게이트 통과 기준

> 숫자와 조건의 SSOT는 `harness/rules.json`이다. 이 섹션은 사람이 읽는 설명이며, 둘이 다르면 `rules.json`이 이긴다.
> 하네스 v1은 1~7단계(G1~G3)만 다룬다. 실행 1회 = 화면 1개.

### G1 — 반영할 부분 고르기 (3단계)
- [ ] 레퍼런스 앱 3개 이상, 화면 6개 이하
- [ ] 반영 목록 1행 이상
- [ ] 반영 목록의 모든 항목에 `story-service.md`의 스토리 번호(1~5)가 있다

### G2 — 화면 설계 문서 (4단계)
- [ ] 대상 화면이 PRD의 4개 화면 중 하나다
- [ ] 주요 요소, 다음 화면 경로, 클릭 경로가 각각 1행 이상이다
- [ ] ★ 클릭 수가 3을 넘는 경로가 없다 (어기면 안 되는 것 1)
- [ ] ★ `add-material` 화면은 자동 불러오기 흐름에서 "분류 제안"이 "사용자 승인"보다 앞에 있다 (어기면 안 되는 것 2)
- [ ] 담당 스토리에 연결된 반영 항목이 S1에 1개 이상 있다. 없으면 S1로 되돌아간다

> 화면 목록은 PRD 4번 섹션 기준이며, PRD에서 아직 "(가정)"이다. 목록이 바뀌면 이 기준도 바꾼다.

### G3 — 컨셉 시안 확정 (7단계)
- [ ] 키스크린 2~3개, 모두 1440×1024
- [ ] 리서치 정리가 비어 있지 않다
- [ ] 사람 승인: 대비 4.5:1 / 3:1과 시안의 질을 확인하고 승인자를 기록한다 (승인 지점은 여기 1곳)
- [ ] 결정 1행, "다시 논의" 상태 0개. 거절되면 S3로 되돌아간다

### G4 — 가이드 위반 검토 (10단계) · 하네스 v1 범위 밖
기준: `harness/default-tokens.md`, `harness/default-rules.md`. 사용자가 정한 값이 있으면 그 값이 우선한다.

**토큰**
- [ ] 화면에 쓴 색·폰트·간격·radius가 모두 토큰에서 나왔다 (직접 입력한 값 0개, R2-3)
- [ ] 토큰 이름에 `light`/`dark`가 없다 (R2-1)
- [ ] 번호 체계가 50~950 하나뿐이다 (R2-2)
- [ ] 토큰마다 값이 하나다 (R2-4)
- [ ] radius가 16px를 넘지 않는다

**접근성**
- [ ] 모든 텍스트 대비가 4.5:1 이상이다 (R1-1)
- [ ] 기능적 경계선은 `border/functional`(gray/500 이상)을 쓴다 (R1-2)
- [ ] `tertiary/500` 위에 흰 글자가 없다 (R1-3)
- [ ] 반투명은 배경 레이어에만 있다. 텍스트·기능 경계는 불투명이다 (R2-5)

**타이포그래피**
- [ ] Pretendard, weight 400/500/700 외의 값이 없다 (R3-1)
- [ ] 큰 글자에 150% 행간을 쓰지 않았다 (R3-3)

**컴포넌트**
- [ ] 컴포넌트가 Figma Variables에 연결돼 있다 (R4-1)
